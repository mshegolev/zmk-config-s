# Product Brief: Sofle ZMK Config

## Executive Summary

Персональный ZMK-конфиг для Sofle V2 с nice!nano v2: одна раздельная клавиатура, переключаемая между двумя macOS-машинами (USB + Bluetooth через 5 BT-профилей). Заточен под интенсивную работу в терминале: home-row mods на ASDF/JKL;, три слоя (default/lower/raise), блокировка. Ключевые нововведения — runtime-запись макросов прямо с клавиатуры (через zmk-behavior-dynamic-macro) и последовательность j→k→j вместо Esc (через zmk-sequences). Оба требуют внешних ZMK-модулей и обновления прошивки с v0.3.0 до актуальной версии.

## The Problem

Два ноутбука — одна клавиатура. Переключение между машинами через Bluetooth (одна по USB, другая по BLE) работает, но теряется мощность раздельной клавиатуры: однообразные макросы (git commit -am, ssh-подключения, tmux-команды) приходится печатать каждый раз вручную. Esc на дальнем углу — лишнее движение при слепой печати.

## The Solution

Один ZMK-конфиг, который расширяет текущую настройку (home-row mods, lower/raise слои, lock) тремя ключевыми вещами:

1. **Runtime-запись макросов** (zmk-behavior-dynamic-macro): два слота на home-row (REC на A/S, PLAY на J/K) на отдельном слое 4 (toogle через комбо MO1+MO2).
2. **Последовательность j→k→j вместо Esc** (zmk-sequences): освобождает от комбо и дальних клавиш.
3. **Обновление ZMK** с v0.3.0 до актуальной версии — необходимо для совместимости с внешними модулями.

## What Makes This Different

- Не «ещё одна раскладка», а персонализация под конкретный сценарий (консоль, macOS, два компа).
- Выбор runtime-макросов вместо статичных даёт гибкость: записал последовательность на лету, а не правил keymap и пересобирал прошивку.
- Честное признание зависимости от внешних модулей и ZMK-апгрейда — не фабричный мод, а живую конфигурацию.

## Who This Serves

Один пользователь (M.v.shchegolev). Разработчик, работающий в консоли (tmux, zsh, редактор, git). macOS на обеих машинах. Требования: слепая печать, минимум движений, макросы на лету.

## Success Criteria

- [C1] Runtime макросы работают: REC → печать → PLAY воспроизводит последовательность.
- [C2] j→k→j выводит Esc без ложных срабатываний на быстром наборе.
- [C3] Конфиг собирается и прошивается на обе половины (left/right) через GitHub Actions.
- [C4] Все существующие фичи (home-row mods, lower/raise, lock, BT-switch) не сломаны.

## Scope

**In:**
- Подключение zmk-behavior-dynamic-macro как внешнего модуля
- Подключение zmk-sequences как внешнего модуля
- Слой 4 (macro) с REC/PLAY/STOP/CANCEL на home-row
- Комбо MO1+MO2 для toggle слоя 4
- Замена комбо J+K→Esc на последовательность j→k→j
- Обновление ZMK revision в west.yml до совместимой
- Добавление CONFIG_ZMK_ZBDM_* и CONFIG_ZMK_SEQUENCES_* в .conf

**Out (V1):**
- LED/OLED индикация записи макросов
- Персистентность макросов через NVS (CONFIG_ZMK_ZBDM_PERSIST — в V2)
- Более 2 слотов макросов
- Энкодеры (физически отсутствуют)
- RGB-подсветка

## Vision

Стабильная конфигурация для ежедневной работы, которая со временем обрастает макросами под частые действия — как git-пайплайны, ssh-туннели и tmux-команды. После V2 — персистентность, чтобы макросы переживали перезагрузку.
